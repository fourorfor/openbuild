Why this file exists
--------------------
`policy.extended.md` is the optional full body behind `policySource: "hybrid"`.
It is never injected by default; the default is the compact OpenBuild kernel in
`policy.default.md`, which now carries the same operating frame in about 5 KB.

The body is a Chinese-operator CTF / red-blue / reverse-engineering prompt. It
carries a routing matrix, delivery discipline, and positive output contracts.
OpenBuild keeps it as close to verbatim as it can because its value is the exact
wording that survives provider-side refusal heuristics; the one revision above is
applied so the body works as an always-on policy rather than a trigger.

The file is user-visible content: `ensure_policy_files_in` writes it once and
never overwrites a later edit. Only a copy whose bytes still match a revision a
previous OpenBuild build shipped verbatim is replaced on upgrade.

Renamed from policy.hanshuang.md
-------------------------------
Earlier builds shipped this body as `policy.hanshuang.md`. It was renamed so the
installed file names carry no activation-word branding. An existing copy of the
old name is left on disk untouched and is no longer read; the plugin reads
`policy.extended.md` only.

Removed predecessor
-------------------
Before that, OpenBuild shipped a dsh-purge 1.1.85 body as `policy.full.md` with a
`NOTICE-dsh-purge.txt` attribution. That body was superseded and both files are
no longer produced. An installed copy is removed by the installer when its bytes
still match the dsh body OpenBuild shipped, so an upgrade does not leave the old
rules pinned in place. A user-edited copy is left alone.
