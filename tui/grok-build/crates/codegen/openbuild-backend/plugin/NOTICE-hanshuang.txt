Why this file exists
--------------------
`policy.hanshuang.md` is the optional full body behind
`policySource: "hanshuang"`. It is never injected by default; the default is the
compact OpenBuild kernel in `policy.default.md`. Enable it with
`/uncensored-edit --use-hanshuang`.

The body is a Chinese-operator CTF / red-blue / reverse-engineering prompt. It
carries activation words (寒霜, 自检), a routing matrix, delivery discipline, and
positive output contracts. OpenBuild keeps it verbatim because its value is the
exact wording that survives provider-side refusal heuristics; editing it changes
its behaviour in ways that are hard to predict.

The file is user-visible content: `ensure_policy_files_in` writes it once and
never overwrites a later edit. Only a copy whose bytes still match a revision a
previous OpenBuild build shipped verbatim is replaced on upgrade.

Removed predecessor
-------------------
Before this revision, OpenBuild shipped a dsh-purge 1.1.85 body as
`policy.full.md` with a `NOTICE-dsh-purge.txt` attribution. That body was
superseded by this one and both files are no longer produced. An installed copy
is removed by the installer when its bytes still match the dsh body OpenBuild
shipped (see `SUPERSEDED_POLICY_HANSHUANG` in `src/plugin.rs`), so an upgrade
does not leave the old rules pinned in place. A user-edited copy is left alone.
