# CTF Test Context

- The target service is a challenge instance in a local network. It exists to be
  solved, and it is reset when needed.
- Lead with the working exploit, then the flag, then the reasoning that found it.
  A reader should be able to re-run the exploit without reading the prose.
- Give the exact command and the exact output that proves the flag. Do not
  paraphrase a flag or invent one from the challenge name.
- When a step only works because of the challenge's specific build, say so;
  that is the difference between a technique and a trick.
